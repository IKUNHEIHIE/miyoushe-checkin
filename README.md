# 米游社自托管签到面板

开源、自托管的米游社多账号管理、社区签到与游戏签到福利项目。每个部署者运行自己的实例，不提供公共注册或账号托管服务。后端由 Codex 开发，前端主要由 Gemini 开发。

**当前版本：v0.2.0，已补齐游戏签到福利及前端入口。** 后端实现契约中的40个操作，支持按角色签到、每日调度和人工验证恢复。原神、星穹铁道与绝区零已完成单账号真实签到和状态复核，其他游戏与渠道的实测范围见接入说明。

## 已验证的关键能力

- 新设备标识、不使用 App 旧 Cookie 或设备 FP 的短信登录。
- 用户手动完成登录阶段的极验 v4 验证，系统提交结果并继续短信流程。
- 获得 stoken_v2，换取 ltoken、工作 cookie_token，独立读取米游币任务。
- 单账号原神社区签到、30 米游币到账复核、重复签到结果核对。
- 单账号原神、星穹铁道、绝区零的签到福利，逐角色复核官方签到状态与奖励记录。

根凭据长期续期、跨真实失效周期恢复、真实多账号、服务器环境、其他社区及其他任务仍待验证。Cookie 保存期限不能当作服务器保证有效期。

## 设计约定

- 后端：TypeScript + Node.js 24 LTS + Fastify 5；SQLite 单机持久化；不引入 Redis 或微服务。
- 前端：由 Gemini 自选框架；通过 HTTP 接口调用后端，不直接访问米哈游账号接口。
- 前后端分开开发；生产环境推荐反向代理到同一站点域名。
- 人机验证由用户手动完成；不集成自动解题或第三方打码服务。
- 账号凭据、短信验证码和真实手机号不得出现在前端日志、Git 仓库或示例文件中。
- 开源许可证尚未由项目所有者选择；正式公开前补齐许可证，不默认继承参考项目许可证。

当前契约版本：`0.2.0`，日期：2026-10-26。后端位于 backend/，前端位于 frontend/；本次按项目所有者要求同步补齐前端签到福利入口。

## Linux 预编译安装

Release 提供 Linux x64 和 arm64 安装包，包含 Node 运行时和应用，不需要 Docker 或本机编译。需要 systemd、curl、tar 和 sha256sum，以 root 运行下载的 `install.sh`。脚本默认安装 v0.2.0，已有安装目录时会停止，不覆盖数据库或密钥。可通过 `MIYOUSHE_VERSION` 指定发布版本。

服务仅绑定服务器本机。远程使用 SSH 隧道：`ssh -L 8080:127.0.0.1:8080 用户名@服务器`，然后访问 `http://127.0.0.1:8080`。首次初始化令牌保存在 `/opt/miyoushe-checkin/.env`，必须同时安全备份此文件和数据库。默认 HTTP 配置只用于本机或 SSH 隧道；公网访问需另行配置 HTTPS、Secure Cookie 和允许的 Origin。

通过推送版本标签触发 GitHub Actions 构建、测试并发布 Release；每个压缩包附带 SHA-256 校验文件。
