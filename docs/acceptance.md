## 测试方式与证据要求

后端业务测试使用虚构账号 A/B、独立 Cookie jar、独立 Challenge 和模拟上游；校验 A 的 token 永远不进入 B 的请求，数据库唯一约束与加密 AAD 也不能互换。模拟成功不能代替真实第二账号验收。

必须测试异步写入超时、上游返回200但retcode失败、短信发送结果未知、重复幂等 key、相同 key 不同请求、版本冲突、进程重启与上海日期边界。测试只验证可观察行为，不以重复实现细节代替业务断言。

前端至少测试用户人工验证交互、验证码字符串、异步轮询终止、按钮防重复、错误分支、密码保留语义和未知余额。模拟数据不得提交到真实官方接口。

真实上游测试只使用管理员明确授权的账号；签到/领奖记录前后状态与时间，不保存令牌或验证码。测试不自动发帖、评论、点赞或分享。
