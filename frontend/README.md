# 米游社签到面板前端

React 19、TypeScript、Vite。契约版本 v0.2.0，与 [OpenAPI](../docs/openapi.json) 保持一致。

## 本地开发

在 frontend/ 中执行：

```powershell
npm ci
npm run dev
```

默认打开 http://127.0.0.1:5173，后端需同时启动在 http://127.0.0.1:3000。Vite 将 /api 请求代理到后端。后端启动方式见 [后端说明](../backend/README.md)。

面板直接请求真实后端，没有模式切换、场景选择、模拟时钟或验证演练台。旧的 ?mode=mock 链接、浏览器模式缓存和 VITE_API_MODE 不再控制请求。连接失败时显示错误与重试按钮。

登录页需输入部署者自己的管理员用户名和密码，不预填演示凭据。首次部署初始化令牌来自后端配置，不保存在前端环境变量中。

## 构建与测试

```powershell
npm run build
npm test -- --testTimeout=15000
```

构建结果在 dist/。生产环境将页面和 /api/v1 接口代理到同一站点；可用 .env.example 配置接口基础路径。

自动化测试在 src/test/ 中拦截HTTP请求提供虚构响应，并替代验证码SDK回调；测试不向官方发送短信或签到。测试夹具不进入应用入口和生产包。人工联调直接使用后端及获授权的真实账号。

## 功能与约定

- 管理员初始化、登录、账号添加与重新登录。
- 用户手动完成人机验证，短信验证码以字符串提交。
- 社区签到领取米游币；签到福利按游戏角色执行并展示游戏奖励。
- 多账号管理、任务偏好、每日计划、凭据检查、运行记录与通知设置。
- Cookie会话与CSRF由集中HTTP客户端管理，凭据不写入浏览器存储或前端日志。

后端接口、签到福利与实测范围见 [前端交接说明](../docs/frontend-handoff.md) 和 [签到福利接入说明](../docs/game-checkin.md)。
